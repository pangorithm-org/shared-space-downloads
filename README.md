# Shared Space 다운로드

Shared Space 운영용 설치 파일을 제공하는 공개 다운로드 저장소입니다. 앱 소스 코드·서명 키·서버 환경 설정은 이 저장소에 포함하지 않습니다.

## 설치 파일

| 운영체제 | 최신 운영용 설치 파일 |
| --- | --- |
| Windows x64 | [Windows 설치 파일 다운로드](https://github.com/pangorithm-org/shared-space-downloads/releases/latest/download/Shared-Space-Windows-x64-setup.exe) |
| Android | [Android APK 다운로드](https://github.com/pangorithm-org/shared-space-downloads/releases/latest/download/Shared-Space-Android.apk) |

- [릴리스와 버전별 다운로드](https://github.com/pangorithm-org/shared-space-downloads/releases)
- [최신 설치 파일의 SHA-256 목록](https://github.com/pangorithm-org/shared-space-downloads/releases/latest/download/SHA256SUMS.txt)

Windows에서는 다운로드한 설치 프로그램을 실행해 설치합니다. Android에서는 APK를 열어 설치하며 기기의 설치 정책에 따라 확인이 필요할 수 있습니다. 다운로드 링크 이용에 GitHub 로그인은 필요하지 않습니다.

## 주의 사항

- 이 파일들은 테스트·데모가 아닌 **실제 운영 서비스**에 접속합니다.
- Windows의 단독 실행 EXE 대신 설치 프로그램을 배포합니다. 앱 링크·기기 알림에 필요한 운영체제 등록을 사용하는 구성입니다.
- 설치 파일의 출처와 SHA-256을 확인하세요. 운영체제의 보안 기능을 임의로 끄지 마세요.
- GitHub가 자동으로 표시하는 **Source code (zip/tar.gz)**는 이 다운로드 저장소의 안내 문서이며, 앱 설치 파일이나 앱 소스 코드가 아닙니다. 위 EXE 또는 APK를 선택하세요.
